⚡ 3 PASOS PARA DEPLOYAR (Total: 30 minutos)

PASO 1: Crear Firebase Project (5 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Ve a https://console.firebase.google.com
2. "Crear proyecto" → "kinesiologos-digitales"
3. Habilita Firestore Database (modo prueba)
4. Copia credenciales
5. Pégalas en .env.local

PASO 2: Agregar Variables de Entorno (2 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Copia .env.example a .env.local
2. Completa con credenciales de Firebase
3. Agrega Claude API key: sk-ant-api03-mLrx4k...
4. Guarda

PASO 3: Deploy a Vercel (10 min)
━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Push a GitHub: git push
2. Ve a https://vercel.com
3. Conecta tu repo
4. Agrega variables de .env.local
5. Click "Deploy"

🎯 RESULTADO: https://kinesiologos-digitales.vercel.app
